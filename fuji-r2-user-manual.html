FUJI R2富士山沙盘控制器

控制器使用说明

TRACK 1、2、3 可独立启停。列车到端后自动停站、换向，往返运行。

认识面板

① 故障指示灯
红灯亮时，记录故障并按第 3 页处理。
② 轨道总控开关
I 允许输出。O 关闭三路轨道输出。
③ 速度旋钮　上方，调本路行驶速度。
④ 长点灯旋钮　下排左侧，调停车点灯。
⑤ 启停按钮　下排中间，按一下启动往返，再按一下停止。灯环亮表示正在自动往返。
⑥ 时间旋钮　下排右侧，调本路升速、减速和停站时间。

上手指南

1　给整机通电

按沙盘侧面的⑨ 控制器总电源按钮。

2　允许轨道输出

③ 速度旋钮先转低。① 故障指示灯熄灭后，② 轨道总控开关拨到 I。

3　启动一路

确认车在线路两端之间。按本路⑤ 启停按钮，再缓慢调高③ 速度旋钮。

4　停止运行

再按本路⑤ 启停按钮停止往返。要关闭三路轨道输出，将② 轨道总控开关拨到 O。

首次调整③ 速度旋钮或⑥ 时间旋钮后，观察一个完整往返，确认列车在两端都能提前停稳。

FUJI R2安装与连接

挂装控制器

安装位置与连接

  1. 将② 轨道总控开关拨到 O，关闭⑨ 控制器总电源按钮。
  2. 左侧留出插拔空间。将⑧ 挂孔的大圆口套在侧板的两颗挂装螺钉上，向下移动盒体约 8 mm，让螺钉滑入窄槽。
  3. 将配套插头插入左侧⑦ DB25 接口，手拧紧插头两端的螺钉。线缆留一点松弛，按第 1 页「上手指南」通电试车。

FUJI R2日常操作

调节与故障排查

④ 长点灯旋钮。本路运行时，先按⑤ 启停按钮停止往返。缓慢调高④ 长点灯旋钮，直到车灯亮、列车不动。列车爬行时调低，换车后重新检查。

⑥ 时间旋钮。顺时针转动会延长升速、端点减速和停站时间。列车停稳后，在停站中点换向，停站结束后发车。

常见现象

看到的现象检查与处理
三路车都不动确认⑨ 控制器总电源按钮已打开、② 轨道总控开关在 I，① 故障指示灯熄灭。按本路⑤ 启停按钮，从低速起步。
⑤ 启停按钮灯环亮，车不动等停站结束，再略调高③ 速度旋钮。若仍不动，清洁车轮和轨面，换一辆正常的车对比。
列车到端不停车，或停车太靠外将② 轨道总控开关拨到 O。检查端点有无遮挡、脏污或车辆脱轨，并在上位机看端点触发计数。若触发正常但停车距离过长，降低③ 速度旋钮，缩短端点减速时间，再低速复测。
停车时车灯灭了，或列车缓慢爬行把④ 长点灯旋钮从低位慢慢调到「灯亮、车不动」。灯亮时若车辆仍在爬行，先调低④ 长点灯旋钮，再检查该车的取电与走行情况。
① 故障指示灯亮红灯将② 轨道总控开关拨到 O，关闭⑨ 控制器总电源按钮，拔掉 USB。排查轨道上的金属杂物和脱轨车辆。排除故障后重新通电，先低速试一路。若① 故障指示灯再次亮起，停用设备并记录线路和发生时机，联系维护人员。

FUJI R2电脑维护

在线调参与固件升级

需要调参、检查输入或升级固件时，再连接电脑。

下载与连接

在 GitHub 下载 Windows 上位机和标准 R2 固件。软件的安装、连接和故障排查见仓库首页的 README。
github.com/GavinGuoUom/fuji-r2-controller

将② 轨道总控开关拨到 O，控制器保持通电。用 USB 数据线连接 Mega2560。打开上位机，选择出现的 COM 端口并点击「连接」。

在线调参

  1. 记录原设置。进入「在线调参」，点击「重新读取」，记录八项设置。
  2. 调整参数。「长点灯」限定④ 长点灯旋钮的最大输出。停站和满量程加速时间各设上下限。减速时间上限为 0 时，到端点直接降至长点灯占空比。开启端点减速后，⑥ 时间旋钮越大，降至该占空比所用的时间越长。
  3. 应用并保存。点「立即应用」。收到回执后，保持② 轨道总控开关在 O，点「保存到控制器」，等待校验通过。更换电位器后，可逐只反向或「全部反向」，再用「引导测试」核对方向。
  4. 试车。「传感器到区间末端」填六个端点中最短的实测余距。逐步提速，确认每次都能在末端前停稳。

固件升级

  1. 先读回并记录参数。将② 轨道总控开关拨到 O，在上位机点击「断开」，关闭其他正在使用该 COM 端口的串口程序。
  2. 按 GitHub README 的「固件升级」步骤，使用 PlatformIO 和 fuji_mega_three_r2 环境上传。确认选中的是这台控制器的 COM 端口。
  3. 刷写时保持 USB 连接，等待校验通过。重新连接上位机，核对② 轨道总控开关为 O、三路输出为零、无故障，并比对保存参数。随后低速试跑，检查端点减速、停站和换向。
适用版本　富士山沙盘交付机使用 Arduino Mega2560 与 Fuji R2 扩展板。请使用下载页标注的标准 R2 固件。
