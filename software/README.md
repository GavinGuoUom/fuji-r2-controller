# Fuji R2 线路调试台

Windows 双击 `launch.cmd`，服务会打开本机浏览器。脚本优先使用 PlatformIO 的 Python 环境。也可以用 Python 3.10 及以上版本，从项目根目录运行 `python -m pip install -r software/requirements.txt` 和 `python software/console.py`。默认地址为 `http://127.0.0.1:8765`。退出时关闭窗口，或在终端按 Ctrl+C。

连接普通 USB 数据线前，把轨道总控拨到 OFF，关闭控制器总电源，确保 USB 未接，并**拔下 R2 扩展板上的 JP3201 跳线帽**。接 USB 期间保持 JP3201 断开。在线调试需要控制器供电时，再打开控制器总电源，轨道总控先保持 OFF。调试结束后，关闭控制器总电源、拔掉 USB，再装回 JP3201。

关闭占用串口的其他程序，在控制台选择 Mega 的串口并连接。串口使用 115200、8N1。没有硬件时可选「离线演示」。

## 使用

- **运行监控**显示输出许可、故障码、三路方向、轨道 PWM、点灯占空比、减速设定、旋钮 ADC、电流原码和端点计数。当前值按约 250 ms 刷新。方向和 PWM 是固件的命令与输出设定。
- **引导测试**可按线路选择总控、旋钮、启动／停止按钮、L/R 传感器、轨道输出和故障灯。实时输入面板显示本路三个旋钮的生效位置和原始 ADC、按钮电平和计数、L/R 端子及脉冲计数。满足步骤条件会自动前进，目视结果可手动确认。新版旋钮自动判定使用固件生效位置。
- **在线调参**可设置长点灯上限、停站与加速范围、传感器余距、端点减速上限。余距记录六个端点中最短的测量值，0 表示未测。减速上限以秒填写，时间旋钮把它映射到 0 至上限，触发端点时锁定本次时长。测定余距后，用实车在最高使用速度下核对停车位置。应用会在线更新，保存须在物理总控 OFF 时进行。

面板负责线路启停。上位机可监控和调参，离线演示中的模拟动作仅更新页面数据。

更换电位器后，在「在线调参 → 旋钮方向」勾选反向的旋钮。九只同向装反时点「全部反向」。总控保持 OFF，依次点「立即应用」和「保存到控制器」。在引导测试中确认逆时针到底为 0%、顺时针到底为 100%。方向设置应用在现有校准之后，校准端点保留。

## 固件

上位机兼容已有 R2 的文本状态协议。端点减速与余距需要 `@CFG 2` 或更新版本，旋钮反向需要 `@CFG 3`。烧录目标为 `fuji_mega_three_r2`，烧录前先断开页面上的串口连接。
